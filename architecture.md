# TinySarf architecture

`analyze` and `analyze.batch` share one serialized internal scheduler. Input is validated before GPU acquisition. Requests reuse the selected backend's device, compute pipelines, int8 weights, uniform buffer and grow-only work buffers. The root-copy model uses twelve passes; the legacy model uses six. An empty batch needs no device. A failed request does not poison later calls. WebGPU device loss raises a clear error; a subsequent call can acquire a fresh device.

The CPU preserves a UTF-16 offset map, strips supported marks and tatweel for inference, and packs each character into a u32 containing a vocabulary ID, position, mark-presence bit and boundary bits. This first student consumes IDs and position embeddings; it does not learn diacritic distinctions. Accepted letters, maximum sizes, rejected inputs and serialization are frozen in [CONTRACT.md](docs/CONTRACT.md).

The multi-task trunk has 32-dimensional character and position embeddings, three 3-tap ReLU convolutions with dilation 1, 2 and 4, per-character segmentation, masked mean pooling, and fixed POS, pattern and feature classifiers. Its original weights remain unchanged in the root-copy candidate.

Root extraction has a separate small CNN with 16-dimensional embeddings and width 48. Four attention heads select input positions, and their weights are accumulated by character ID. Four learned generators can supply missing radicals; a sigmoid gate mixes copying and generation independently for each radical. Repeated positions can supply doubled roots. This replaces the old four independent classifiers over the multi-task mean vector, at approximately the same total parameter count. PyTorch and an independent NumPy implementation define both paths.

Every tensor is quantized independently to symmetric signed int8 with a float32 scale. Tensors begin at four-byte boundaries. WGSL extracts signed bytes from packed u32 words and multiplies them by tensor scales. Padding embedding rows are physically present but unreachable and excluded from the reachable-weight count. Tensor shapes, offsets, lengths, scales, class order, vocabulary, architecture, learned root transformations and SHA-256 are checked before inference.

Six compute passes implement the multi-task embedding, convolutions, pooling and classifiers. Six additional passes implement the root embedding, convolutions, pooling and copy/generator mixture. The final root pass writes only root columns in the shared output. Both branches reuse the same alternating activation and pooling buffers. Inputs use length classes 8/16/32. Buffer capacity grows by power-of-two batch classes. Logical batches up to 2,048 words are processed in internal chunks of at most 256. Weights, pipelines and bind groups remain resident; bind groups are recreated only when buffers grow.

The CPU decoder uses a monotone span grammar, lexical constraints for common conjunction/preposition/article prefixes, and an approximate beam over the other heads. Root candidates also use surface-to-radical transformations learned from training words and aligned stems. Every transformation copies at least two distinct positions and has support from at least three different training roots. It can repeat a copied radical or restore an absent radical. Neural alternatives remain available with a measured penalty; transformations do not guarantee linguistic correctness. Root constraints use the same best valid segmentation as the public analysis. The decoder serializes applicable features, deduplicates candidates, and maps spans back to the original input. Scores are ranking scores, not calibrated probabilities, and top-3 does not exhaust morphological ambiguity.

The runtime contains no word-to-root dictionary. Legacy multi-task training samples one mappable teacher analysis per word each epoch. Root training separately retains usable root labels even when morpheme pieces cannot be aligned to the surface. It marginalizes over unique complete roots, avoiding duplicate-analysis weighting and incompatible per-slot reference combinations. Protected evaluation inputs and full teacher lemma identities, including ambiguity-connected aliases, are excluded from new root training. The inherited multi-task checkpoint keeps its original exploratory provenance. Teacher sampling is not a natural text distribution. The final-test split remains sealed, and no independently human-labelled gold dataset is present.

The benchmark package compares float and int8 CPU predictions and quantized CPU/WebGPU tensors and decoded outputs. Browser timing surrounds the public API; diagnostic phase timing is supplementary. Artifact JSON retains raw samples, counts, bootstrap settings, model/data hashes, commands, source status and available hardware metadata. Unmeasured values are null. Results and documentation never turn teacher agreement into gold accuracy.

Promotion is a separate guarded operation. Experimental selection does not write `active/`. A public release requires independent gold, reviewed fixtures, parity, protected-slice checks, engineering budgets and clean-clone reproduction. Missing evidence fails closed.
