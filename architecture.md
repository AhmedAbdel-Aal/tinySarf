# TinySarf architecture

`analyze` and `analyze.batch` share one serialized internal scheduler. Input is validated before GPU acquisition. Requests reuse the selected backend's device, six compute pipelines, int8 weights, uniform buffer and grow-only work buffers. An empty batch needs no device. A failed request does not poison later calls. WebGPU device loss raises a clear error; a subsequent call can acquire a fresh device.

The CPU preserves a UTF-16 offset map, strips supported marks and tatweel for inference, and packs each character into a u32 containing a vocabulary ID, position, mark-presence bit and boundary bits. This first student consumes IDs and position embeddings; it does not learn diacritic distinctions. Accepted letters, maximum sizes, rejected inputs and serialization are frozen in [CONTRACT.md](docs/CONTRACT.md).

The float reference is a PyTorch CNN with 32-dimensional character and position embeddings, three 3-tap ReLU convolutions with dilation 1, 2 and 4, per-character segmentation, masked mean pooling, and fixed POS, four radical, pattern and feature classifiers. NumPy implements the same operations independently. The three initial candidates target roughly 50K, 100K and 250K parameters; exact counts are generated from tensors.

Every tensor is quantized independently to symmetric signed int8 with a float32 scale. Tensors begin at four-byte boundaries. WGSL extracts signed bytes from packed u32 words and multiplies them by tensor scales. The embedding padding row is physically present but unreachable; it is excluded from the reachable-weight count. Tensor shapes, offsets, lengths, scales, class order, vocabulary, normalization version and SHA-256 are checked before inference.

Six compute passes implement embedding, the three convolutions, pooling and all classification heads. Inputs use length classes 8/16/32. Buffer capacity grows by power-of-two batch classes. Logical batches up to 2,048 words are processed in internal chunks of at most 256 to bound memory. Intermediate activations use two alternating buffers. Weights, pipelines and bind groups remain resident; bind groups are recreated only when buffers grow.

The CPU decoder uses a monotone span grammar, lexical constraints for common conjunction/preposition/article prefixes, structured three/four-radical candidates, and an approximate beam over the other heads. It serializes applicable features, handles unknown values, deduplicates candidates, and maps spans back to the original input. Scores are average log ranking scores. They are not calibrated probabilities, and top-3 does not exhaust morphological ambiguity.

The runtime contains no dictionary. Training preserves every distinct *mappable* teacher analysis and samples one uniformly per word each epoch. Surface-connected lemma families cannot cross splits. The initial unrestricted dataset was marked ineligible before training because proper names dominated it; the revised lexical sample and the audit are versioned. Teacher sampling is not a natural text distribution. The final-test split remains sealed, and no independently human-labelled gold dataset is present.

The benchmark package compares float and int8 CPU predictions and quantized CPU/WebGPU tensors and decoded outputs. Browser timing surrounds the public API; diagnostic phase timing is supplementary. Artifact JSON retains raw samples, counts, bootstrap settings, model/data hashes, commands, source status and available hardware metadata. Unmeasured values are null. Results and documentation never turn teacher agreement into gold accuracy.

Promotion is a separate guarded operation. Experimental selection does not write `active/`. A public release requires independent gold, reviewed fixtures, parity, protected-slice checks, engineering budgets and clean-clone reproduction. Missing evidence fails closed.
